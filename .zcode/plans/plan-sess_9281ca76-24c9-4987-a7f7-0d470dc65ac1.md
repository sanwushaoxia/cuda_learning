# CUDA 编程学习指导:从初学者到专家

在 `/home/tars/Code/ai_model/module/cuda` 下建设一个中文教学向 CUDA 学习模块,沿用仓库现有文档风格(参考 `module/pytorch_ex/README.md`:目录结构/依赖/文件说明/建议阅读顺序)。环境:RTX 3060(sm_86, 12GB)+ CUDA 12.4 + conda py312。

## 各阶段内容(每个阶段 = README.md 讲解 + 示例代码 + exercises/ 待实现骨架 + solutions/ 参考答案)

**01_basics — 初学者:编程模型**
- 示例:`hello_world.cu`(已有)、`vector_add.cu`(改为多 block 并行版,原单线程版保留对照)、`device_info.cu`(查询 GPU 属性、错误检查宏 `CUDA_CHECK`)。
- 讲解:kernel 语法、thread/block/grid 层次、launch 配置、错误处理惯例。
- 练习:saxpy;二维 grid 打印线程坐标(理解全局索引)。

**02_memory — 内存层次**
- 示例:`mem_transfer.cu`(cudaMalloc/cudaMemcpy/cudaFree 完整生命周期)、`pinned_memory.cu`(页锁定内存加速传输)、`unified_memory.cu`(cudaMallocManaged)。
- 讲解:全局/共享/常量/纹理内存层次,PCIe 传输带宽估算,host-device 传输是常见瓶颈。
- 练习:实现矩阵转置(naive 版,为阶段三铺垫);测量不同传输方式耗时。

**03_shmem — 共享内存与线程协作**
- 示例:`matmul_tiled.cu`(分块矩阵乘,与 naive 版对比)、`reduce_basic.cu`(相邻配对/交错配对归约)。
- 讲解:`__shared__`、`__syncthreads()`、bank conflict、thread coarsening。
- 练习:分块矩阵转置(消除 bank conflict);1D stencil。

**04_optimize — 优化与 profiling(专家核心)**
- 示例:`reduce_warp.cu`(warp shuffle 优化归约)、`occupancy.cu`(occupancy API 与 block 尺寸扫描)、`coalesce.cu`(合并访存 vs 非合并对比基准)。
- 讲解:roofline 思维、Nsight Systems (nsys) 与 Nsight Compute (ncu) 工作流——复用现有 `report1` 经验、常见指标(带宽利用率、occupancy、warp divergence)。
- 练习:把阶段三的 matmul 优化到位并出 profiling 报告对比。

**05_streams — 并发**
- 示例:`stream_overlap.cu`(计算与传输重叠)、`multi_stream.cu`(多流并发 kernel)、`cuda_graph.cu`(CUDA Graph 降 launch 开销)。
- 讲解:stream 语义、event 计时、默认流陷阱、Graph 适用场景。
- 练习:把 vector_add 流水线化(分块 + 双流)。

**06_pytorch — 互操作**
- 示例:`extension/`(用 `torch.utils.cpp_extension.load` 写自定义算子:CPU/PyTorch/CUDA 三方耗时对比,在 py312 环境运行,与 cu124 对齐)。
- 讲解:tensor.data_ptr 接入、stream 与 PyTorch current stream 配合、编译扩展的两种方式。
- 练习:实现自定义 fused saxpy 扩展。

## 构建系统

`Makefile`:检测 `nvcc`,统一 flags `-O3 -arch=sm_86 -std=c++17`(本机 RTX 3060);用通配符收集各阶段 `*.cu` 到 `build/` 目录输出;提供 `make all`、`make clean`、`make run T=<name>`、`make profile T=<name>`(nsys)。06_pytorch 用 python 侧脚本编译,不进 Makefile。
