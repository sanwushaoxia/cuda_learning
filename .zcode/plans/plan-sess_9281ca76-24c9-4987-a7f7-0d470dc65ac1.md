# module/cuda 双 GPU 配置:保留 GTX 750 Ti,新增 RTX 3060(默认)

## 现状与目标

- `Makefile` 当前硬编码 GTX 750 Ti(sm_50)+ CUDA 11.8 + Windows 包装脚本;Linux 分支的 `CUDA_HOME` 还指向 Windows 路径(本机实际已不可编译)。
- `tools/nvcc_win.cmd` 硬编码 CUDA v11.8 路径。
- README 第 5 行/成绩单仍是 RTX 3060 旧文案,与环境表(750Ti)自相矛盾。
- 目标:**默认 RTX 3060(sm_86 + CUDA 12.4,本机 Linux)**,可切换回 **GTX 750 Ti(sm_50 + CUDA 11.8,Windows 机)**;通过配置文件切换。

## 配置设计(配置文件切换)

新增 `configs/` 目录,每台机器一个 profile 文件:

```
module/cuda/
├── config.mk              # 选择开关:GPU_PROFILE ?= rtx3060(默认),include configs/$(GPU_PROFILE).mk
├── configs/
│   ├── rtx3060.mk         # 新增:Linux + sm_86 + CUDA 12.4
│   └── gtx750ti.mk        # 迁移现有:Windows + sm_50 + CUDA 11.8 + nvcc_win.cmd
└── Makefile               # -include config.mk,各变量由 profile 提供
```

- **configs/rtx3060.mk**:`GPU_ARCH := sm_86`、`CUDA_HOME ?= /usr/local/cuda`(v12.4)、`USE_WIN_WRAPPER := 0`。
- **configs/gtx750ti.mk**:`GPU_ARCH := sm_50`、`CUDA_HOME := C:/Program Files/.../CUDA/v11.8`、`USE_WIN_WRAPPER := 1`。
- `config.mk` 只有一行选择 `GPU_PROFILE ?= rtx3060`(改文件或 `make GPU_PROFILE=gtx750ti` 均可覆盖)。
- 兼容性:`config.mk` / profile 变量全部用 `?=` 级别可覆盖,原有 `make NVCCFLAGS=...` 用法不受影响。

## Makefile 修改

1. 头部 `-include config.mk`(文件不存在也不报错,此时回退内置默认 = rtx3060)。
2. `NVCCFLAGS ?= -O3 -arch=$(GPU_ARCH) -std=c++17`;删除硬编码的 sm_50 与 Windows CUDA_HOME 默认值。
3. Windows 分支由 `USE_WIN_WRAPPER` 决定是否走 `tools\nvcc_win.cmd`(750Ti profile 开,rtx3060 profile 关);Linux 分支 `NVCC := "$(CUDA_HOME)/bin/nvcc"` 恢复可用。
4. `BUILD_DIR := build/$(GPU_PROFILE)` —— 切换 profile 后产物隔离,不混入旧架构二进制(免去切换时忘记 make clean)。
5. `help` 目标打印当前 profile 与架构。

## tools/nvcc_win.cmd 修改

把硬编码的 `CUDA_PATH=...v11.8` 改为可参数化:优先用外部传入的 `CUDA_PATH`/`CUDA_VER` 环境变量,缺省仍是 v11.8(750Ti 现状不变);VS2019 vcvars 检测逻辑保留(CUDA 11.8 与 12.4 均兼容 VS2019)。

## README 修改

1. 环境准备改为**双机表格**(750Ti: Windows/CUDA 11.8/sm_50;RTX 3060: Linux/CUDA 12.4/sm_86,标注默认),消除第 5 行矛盾文案。
2. 构建速查增加配置切换说明:改 `config.mk` 或 `make GPU_PROFILE=gtx750ti`;切换后产物在 `build/<profile>/` 互不覆盖。
3. 实测成绩单标注为"RTX 3060 实测",注明 750Ti 平台数据待补充(sm_50 上部分示例如 CUDA Graph 需 9.0+ 特性时可能不适用,README 提示)。
4. 阶段六(py312 + cu124)标注仅适用于 RTX 3060 本机。
